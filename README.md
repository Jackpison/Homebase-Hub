## Features

Six pages share one login, one bar and one Settings page. Pick a name to see its own page on the website.

| Page | What it does | Highlights |
|---|---|---|
| [🏠&nbsp;**Home**](https://jackpison.github.io/Homebase-Hub/features/home/) | A start page that feels like yours | Background photos that change, phone-sized copies that load fast, with or without the bar |
| [🔖&nbsp;**Links**](https://jackpison.github.io/Homebase-Hub/features/links/) | Bookmarks in tabs and categories | Import from any browser, icons saved on your server, colours and sizes for each tab, encrypted tabs |
| [📝&nbsp;**Info**](https://jackpison.github.io/Homebase-Hub/features/info/) | Notes in boxes, or as a document | 1 to 12 boxes in each tab, cards or one document with an outline, export as PDF or text |
| [💳&nbsp;**Cards**](https://jackpison.github.io/Homebase-Hub/features/cards/) | Your cards in one searchable table | Filter by bank, network, type and holder, yearly charges added up, export to Excel |
| [✅&nbsp;**Tasks**](https://jackpison.github.io/Homebase-Hub/features/tasks/) | Bills, renewals and chores | Due dates, repeats and prices, calendar and analytics, Year in Review PDF |
| [🧰&nbsp;**Tools**](https://jackpison.github.io/Homebase-Hub/features/tools/) | Small tools that run in your browser | 36 tools: resize, crop and convert images, merge and sign PDFs, OCR, QR codes |

And around the pages:

| Extra | What you get |
|---|---|
| ⚙️&nbsp;**Settings** | Guided Setup for protection, 166 looks and your own colours, backup and restore, updates and health checks |
| ✈️&nbsp;**[Telegram](#telegram)** | A daily digest, Due Now messages with Done, Skip and Snooze buttons, and backup files sent to your chat |
| 📱&nbsp;**On your phone** | Add the site to the home screen of a phone or computer and it opens like an app, with its own icon and no browser bars (Settings > General > Install on Your Phone). Nothing is kept offline: your data always comes from your server |
| 🛡️&nbsp;**[Security](#security-in-short)** | One password, optional two-step login, encrypted tabs and backups, and checked updates you can undo |

## Install

### Requirements

| You need | Details |
|---|---|
| **Hosting** | PHP 8.3 or newer (tested on 8.3, 8.4 and 8.5) |
| **Access** | A file manager or FTP |
| **HTTPS** | Recommended |
| **Database** | None |

### Quick start

1. Download `site-update-X.Y.Z.zip` from the [latest release](https://github.com/Jackpison/Homebase-Hub/releases/latest).
2. In your hosting file manager, upload it to your domain's folder (for example `public_html`) and extract it there.
3. Open your domain and click the key icon. Enter the setup code from `site-data/core/SETUP-CODE.php` and choose a password.

> [!TIP]
> Open **Settings > Overview > Guided Setup** next. It walks you through a strong password, two-step login, an encryption passphrase, a first backup and Telegram, one step at a time.

> [!WARNING]
> **Never delete `site-data`.** It holds all your data, and updates never touch it.

### Updating

Open **Settings > Updates**.

1. Press **Check Now** to look for a new version on GitHub. The daily check is off unless you turn it on.
2. Press **Download and Check**. The download is verified against its SHA-256, and you see what will change.
3. Apply it with your password. A copy of the current version is kept first, and **Go Back** restores it.

You can also upload a zip in the same place.

> [!NOTE]
> An update that needs a newer PHP than your server has is refused, and nothing changes.

## Telegram

Optional. Set it up in **Settings > Telegram** and your site can message you:

- **A daily digest** of what is due.
- **Due Now messages** with **Done**, **Skip** and **Snooze** buttons (1 Hour, 3 Hours or Tomorrow).
- **Backup files** sent to your chat.
- **Commands** you can type to the bot:

| Command | What it does |
|---|---|
| `/today` | Overdue and due today, with Done buttons |
| `/week` | The next 7 days |
| `/next` | The next 10 tasks |
| `/add Netflix 649 monthly 5 Nov` | A new task (price, repeat, date and time are optional) |
| `/done Netflix` | Mark a task done |
| `/snooze Netflix 2h` | Pause its reminders (30m, 2h, 1d or tomorrow) |
| `/backup` | Send a backup file now |
| `/status` | A quick check of the site |

## Security in short

| Area | What it does |
|---|---|
| 🔑&nbsp;**Login** | One bcrypt password, optional two-step login with recovery codes, trusted browsers and a device list. Logins pause after five wrong tries. |
| 🔐&nbsp;**Encryption** | Tabs in Links and Info and your backups can be encrypted. The keys are made in your browser from your passphrase, so a lost passphrase and recovery key means lost data. |
| 🚪&nbsp;**Closed data** | Data files answer 404 to a browser, even on hosts where `.htaccess` is ignored. |
| ♻️&nbsp;**Safe updates** | They come only from this project's GitHub releases, are compared with the release's SHA-256 checksum and fully checked before anything changes, and need your password. |
| ⏳&nbsp;**PHP support** | Settings tells you when your PHP stops getting security fixes. |

More on the [Security page](https://jackpison.github.io/Homebase-Hub/security/). To report a problem, [open an issue](https://github.com/Jackpison/Homebase-Hub/issues/new/choose). For anything else, message me on Telegram: [@Jackpison](https://t.me/Jackpison).

### Where things are stored

| What | Where |
|---|---|
| Your data: pages, settings, login, backups | `site-data/` in your site folder, closed to browsers |
| Your logo, start page photos and saved link icons | `web/hub/media/`, never replaced by an update |
| The README, changelog and readable source | `web/hub/docs/`, closed to browsers |

## FAQ

<details>
<summary><b>Do I need a database?</b></summary>
<br>
No. Everything is kept as files in <code>site-data/</code>, which is closed to browsers.
</details>

<details>
<summary><b>What kind of hosting do I need?</b></summary>
<br>
Any hosting with PHP 8.3 or newer and a file manager (or FTP). HTTPS is recommended. Settings tells you when your PHP is about to stop getting security fixes.
</details>

<details>
<summary><b>Can I put it in a sub-folder?</b></summary>
<br>
Yes. Upload it to a folder such as <code>/hub/</code> and it works the same, including installing it on a phone.
</details>

<details>
<summary><b>Can I bring my bookmarks from my browser?</b></summary>
<br>
Yes. Export them from Chrome, Edge, Firefox, Brave, Opera or Safari, then choose <b>Import Bookmarks</b> in the Links pencil menu. You see a preview first.
</details>

<details>
<summary><b>Does it work offline?</b></summary>
<br>
No, on purpose. Your data is private, so it always comes from your server. Added to a home screen, the site opens like an app, but nothing is kept on the phone.
</details>

<details>
<summary><b>What if an update goes wrong?</b></summary>
<br>
A copy of the current version is kept before every update, and <b>Go Back</b> in Settings > Updates restores it. Your data in <code>site-data/</code> is never touched by an update.
</details>

## Contributing

Bug reports and ideas are welcome. [CONTRIBUTING.md](.github/CONTRIBUTING.md) has the short version, and [AGENTS.md](AGENTS.md) lists every check to run before a change.

### Building and testing

The readable source is in `src/`. To build the update zip you need Python 3 and Node:

```
npm ci
python3 scripts/build.py
```

This writes `build/site-update-X.Y.Z.zip` and its `.sha256`. `python3 scripts/make-site.py` builds the website and the PDF guide into `build/site`. The tests are described in [tests/README.md](tests/README.md).

### Releases

`python3 scripts/release.py X.Y.Z` raises the version everywhere, and `python3 scripts/release.py --check` checks that it agrees. A release is made by pushing a tag `vX.Y.Z` that matches the version in `src/web/hub/core/lib/boot.php`. The release workflow builds the zip, publishes the release and updates the website.
