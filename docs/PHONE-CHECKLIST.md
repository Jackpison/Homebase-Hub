# Checking a release on a real phone

The tests drive real browsers, but not a real phone, a real finger or a real camera. After a release that touches the look, the bar,
gestures, the clipboard or the phone app, go through this list on an iPhone (and an Android phone if you have one). It takes about ten minutes.

Open the site in the browser first, then once from the icon on the home screen (the installed app).

## Moving around
- [ ] Swipe left and right on Links, Info, Cards, Tasks and Files: the page follows your finger, a short swipe springs back, a full one opens the next page.
- [ ] On Home, pull down from the top: the next background comes.
- [ ] Scroll a long page: the top bar slides away and comes back on a scroll up, without a stutter.
- [ ] Turn on Reduce Motion (iPhone: Settings > Accessibility > Motion) and swipe again: nothing slides, the page fades.

## Typing and copying
- [ ] Settings > Security > Encryption: the recovery key shows in full, on two lines if needed; the copy icon says COPIED and pastes correctly in Notes.
- [ ] Settings > Security > Two-Step Login > Set Up: the key shows in full; Copy and paste it into the authenticator app.
- [ ] Links > Add Link: paste an address; the https:// moves into the box in front.
- [ ] Files > a file > Share: the link copies.

## Offline Reading (when switched on for this phone)
- [ ] Open Links, Info and Tasks once, turn on Airplane Mode, open the app from the home screen: the pages show with "Offline" and cannot be edited.
- [ ] Turn Airplane Mode off: the pages refresh by themselves.

## Things only a phone has
- [ ] Tools > QR Code Scanner (or any tool with the camera): the camera opens, a code is read.
- [ ] Share a link from another app to Homebase Hub (Android, or the iPhone Shortcut): it lands in Links.
- [ ] The status bar (clock, battery) never covers the bar's buttons.

Write down anything odd (which page, what you did, a screenshot) and pass it on with the next request.
