Install

You need a web host with PHP 8.3 or newer and a file manager (or FTP). HTTPS is recommended. On your own server you can also use Docker or set it up on a VPS.

First install

  1. Download site-update-X.Y.Z.zip from the latest release.
  2. In your hosting file manager open the folder of your domain (for example public_html), upload the zip and extract it there.
  3. Open your domain in a browser and click the key icon (top right). A welcome box opens.
  4. In the file manager open site-data/core/SETUP-CODE.php and copy the code from the line that starts with SETUP CODE:. It is a PHP file only so that a browser gets a 404 for it.
  5. Paste the code, choose a site name and a password, and press Create my site.

Never delete site-data. It holds all your data, and updates never touch it.

Updating later

Open Settings, then Updates.

  • From GitHub: press Check Now. If a newer version exists, press Download and Check. Review what will change, type your website password, and apply. The daily check is off by default.
  • By zip: upload the new zip in the same tab.

Before anything is replaced the site saves the version it has, and afterwards it looks at itself. If it cannot answer, the saved version comes back by itself. Go Back does the same on request.

A site on 1.49 or older (before the folder layout of 1.50): update to 1.59.1 first, then to the newest version. From 1.60 the updater no longer installs, or goes back to, versions from before 1.50.

Docker

Each release is also a Docker image, for PCs, servers and Raspberry Pi: ghcr.io/jackpison/homebase-hub. It holds PHP and Apache, so the site's own protection works exactly as on a web host.

  1. Download compose.yaml into an empty folder and run docker compose up -d there.
  2. Open http://your-server:8080 and click the key icon.
  3. Get the setup code with docker compose exec hub cat site-data/core/SETUP-CODE.php and finish as in First install.

With HTTPS: passkeys, offline reading and installing on a phone need HTTPS. Point your domain at the server, download compose.caddy.yaml and the Caddyfile into one folder, and run HUB_DOMAIN=hub.example.com docker compose -f compose.caddy.yaml up -d. Caddy gets the certificate by itself.

The first start copies the site into a volume, where your data lives too. Update from Settings, Updates, as on any host: a newer image never replaces a site that is already there. Keep the volume (do not use docker compose down -v), and export a backup now and then.

On a VPS

For a server of your own with Ubuntu 24.04 or Debian 13, using Apache:

  1. Install Apache and PHP: sudo apt install apache2 libapache2-mod-php php-curl php-gd php-intl php-mbstring php-zip unzip, then sudo a2enmod headers rewrite mime deflate.
  2. Download site-update-X.Y.Z.zip and its .sha256 file from the latest release and check it: sha256sum -c site-update-X.Y.Z.zip.sha256 must say OK.
  3. Extract it: sudo mkdir -p /var/www/homebase-hub && sudo unzip site-update-X.Y.Z.zip -d /var/www/homebase-hub && sudo chown -R www-data:www-data /var/www/homebase-hub. The web server must own the files, so Settings, Updates can replace them.
  4. Copy homebase-hub.conf to /etc/apache2/sites-available/, put in your domain, and run sudo a2ensite homebase-hub && sudo systemctl reload apache2.
  5. HTTPS: sudo apt install certbot python3-certbot-apache && sudo certbot --apache -d hub.example.com.
  6. Open your domain, click the key icon, and get the setup code with sudo cat /var/www/homebase-hub/site-data/core/SETUP-CODE.php.

nginx instead of Apache: nginx ignores the site's .htaccess files, so it needs homebase-hub.conf for nginx, which keeps site-data closed and sends the same security headers. Install nginx php-fpm and the same PHP packages, and use certbot --nginx. Without that file your data folder would be open to anyone.

Behind your own proxy (Caddy, nginx, Traefik or a load balancer in front of the site): set HUB_TRUSTED_PROXY to the proxy's address, so the site sees each visitor's address and HTTPS. Only the addresses you list are believed.

Keeping it safe

The site needs no regular work. The one thing to watch is the PHP version on your hosting: each version gets security fixes for about four years. Homebase Hub needs PHP 8.3 or newer, and Settings tells you when yours is about to stop getting fixes. An update that needs a newer PHP than your server has is refused, and nothing changes.

Moving or copying the site

Copy the whole site folder, data included, or export a backup and import it on the new site.

Forgot the password

Delete site-data/core/auth.php in your file manager, open the site, click the key icon, and use the setup code from site-data/core/SETUP-CODE.php. Encrypted tabs are locked with your passphrase, so a reset does not touch them.
