# Contributing

- **Bugs:** open a GitHub Issue with the version (Settings > Changelog), what you did, what you expected, what happened.
- **Feature requests and questions:** message [@Jackpison](https://t.me/Jackpison) on Telegram.
- **Code:** edit the readable files in `src/`, never minified output. Every release bumps the version in `src/web/core-data/lib/boot.php` (`HUB`) and every `?v=`, adds a CHANGELOG entry and a Version Map row. Read `docs/PROJECT-HANDOFF.md` (Part A rules) first.
- Never commit `site-data/`, passwords, tokens or `config.php`.
